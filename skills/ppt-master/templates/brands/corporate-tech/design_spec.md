# Corporate Tech 品牌规范

> 全局品牌约束：白色背景，深蓝色主题，绿色/灰色辅助，避免活泼颜色

## 适用场景

- 技术方案评审
- 代码优化汇报
- 架构设计分享
- 技术文档演示
- 企业内部汇报

---

## Color Scheme

### 主题色彩

| Role | HEX | Color Name | Purpose |
| ---- | --- | ---------- | ------- |
| **Background** | `#FFFFFF` | Pure White | 页面背景 |
| **Secondary bg** | `#F5F7FA` | Light Gray Blue | 卡片背景、区块背景 |
| **Primary** | `#2E5090` | Medium Blue | 标题装饰、关键区域、图标 |
| **Accent** | `#2E7D32` | Forest Green | 数据高亮、成功状态 |
| **Secondary accent** | `#607D8B` | Blue Gray | 次要强调、辅助信息 |

### 文字色彩

| Role | HEX | Purpose |
| ---- | --- | ------- |
| **Body text** | `#1A1A2E` | 主文本（近黑深蓝） |
| **Secondary text** | `#5A6A7A` | 说明文字、注释 |
| **Tertiary text** | `#8A95A5` | 补充信息、页脚 |

### 边框与状态

| Role | HEX | Purpose |
| ---- | --- | ------- |
| **Border** | `#D0D8E0` | 卡片边框、分隔线 |
| **Success** | `#2E7D32` | 正面指标、成功状态 |
| **Warning** | `#F57C00` | 警告标记（谨慎使用） |
| **Error** | `#C62828` | 错误标记（谨慎使用） |

### 禁用颜色

以下颜色**不应使用**（活泼性颜色）：
- ❌ 亮橙色 `#FF9800`
- ❌ 亮黄色 `#FFEB3B`
- ❌ 粉红色 `#E91E63`
- ❌ 紫色 `#9C27B0`
- ❌ 亮青色 `#00BCD4`

## Visual Guidelines

### Layout

- 白色背景为主，浅灰蓝作为区块背景
- 卡片使用 1px 浅灰蓝边框，8px 圆角
- 内容间距 20-32px
- 安全边距：左右 60px，上 50px，下 40px

### Data Visualization

- 主数据使用中蓝色 `#2E5090`
- 正向数据使用深绿色 `#2E7D32`
- 对比数据使用蓝灰色 `#607D8B`
- 避免使用渐变和发光效果

### Code Snippets

- 代码块背景：`#F5F7FA`
- 代码字体：`Consolas, "Courier New", monospace`
- 代码字号：14-16px

---

## Application Notes

1. **保持专业感**：使用深蓝色和灰色调，传达可信赖的技术形象
2. **数据清晰**：表格和图表使用足够的对比度
3. **避免装饰**：不使用渐变、阴影、发光效果
4. **代码可读**：等宽字体，浅色背景，足够字号
